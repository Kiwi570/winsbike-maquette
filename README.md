# Winsbike — maquette

Site statique (HTML, CSS, JS) sans étape de construction. Déploiement Vercel : `vercel.json` active les adresses propres.

La maquette est volontairement exclue des moteurs de recherche (balise robots, en-tête X-Robots-Tag et robots.txt) : elle reprend les prix et le nom d'une entreprise réelle avec un panier simulé. À retirer lors de la mise en production, avec l'adresse PREVIEW de build.py.
